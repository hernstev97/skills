# Skills

I find these useful and plan on expanding this repo with skills I find online (maybe change), write myself or generate in coop with an agent.

## unslop

Strips AI writing patterns. I run this on anything that should sound human.

## bro

Restates the last message in plain language. No jargon.

## how

Answers "how does this work?" Explores the codebase and explains architecture, flow, and where things live.

## why

Answers "why is it built this way?" Searches git, tickets, docs, chat, and observability for evidence.

## teach

Runs `how` and `why`, then explains the thing in one plain account. For understanding, not changing code.
